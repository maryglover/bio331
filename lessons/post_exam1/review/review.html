Filter

We can use the filter function to only view rows that meet a certain criteria using:

  • == : equals
  • > : greater than
  • < : less than
  • != : not equal to
  • >= : greater than or equal to
  • <= : less than or equal to
  • : or
  • %in% : matches contents of a vector

The filter function takes arguments for data and the criteria for filtering the data based on a specific column.

For example, the following code, will first filter the data to only include songs where the Happiness score is under 50 and the Artist is Taylor Swift.

music |>
  filter(Happiness < 50, Artist == 'Taylor Swift')

Change the code so that the Happiness is more than 50 and the Artist is The Beatles

With numbers, you do not need to use quotation marks. If you want the row to match text, you must put the text in quotes.

Mutate

The last dplyr function we will review is mutate. mutate is used to make calculations based on the columns and make a new column with the results.

mutate expects the format: mutate(New_column_name = column calculation). For example, if we wanted to get the difference of the Happiness and Danceability, we could use mutate and make a new column we will call diff. The column calculation is therefore Happiness - Danceability So it looks like this:

mutate(diff = Happiness - Danceability).

Data visualization with ggplot2

Now, we will work on our graphing with ggplot.

ggplot2 uses what are called “layers” to plot data. These layers are added on one another to produce the visualization.

The first layer sets the foundation and uses the function ggplot(). The ggplot() function expects:

  1. the data you are plotting
  2. the aesthetic mapping aes(). This provides the columns that will be displayed on the graph. For example, the what column is the x axis and which is the y axis.

Then, we will add one of the geom layers to plot data.

  • geom_point: plots points for a scatterplot
  • geom_bar: barplot
  • geom_boxplot: boxplot
  • geom_line: line graph.
  • geom_histogram: a histogram.

Let’s start with a scatterplot, where we look at the relationship between Danceability and Happiness. Also, The first time we run a ggplot2 function, we must load in the package. Fill in the blank to add the geom_point()l layer

Themes

Next, we will add a theme to the plot. This will change the overall look of the plot. There are many preset themes in ggplot2. Here are some:

Labels

Our last customization will use the function labs(). In labs, you can specify

  • x =: to change the x axis title
  • y =: to change the y axis title
  • title = : to add a title to the graph.

Like theme_*, we add the labs function to the existing plot.

Let’s say we want to add units to the Length y axis label in our last plot. We can do that in labs as:

ggplot(music, aes(x=Happiness, y = Danceability)) + 
  geom_point() +
  theme_classic()+
  labs(y = "Length in minutes")

labs expects the titles to be in quotations. Edit the code to add a title to the plot as well.
